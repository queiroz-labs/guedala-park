- Giro atual55°, extração do saco e desmontagem para acesso ao sifão. Não aumentar gabinete, deslocar hidráulica ou trocar por cesto rígido para ocultar incompatibilidade.

## O que falta para selecionar

Uma ferragem precisa demonstrar **eixo real + dobradiça + braço de controle + limite/retentor + fixações**, com8kg de roupa como meta provisória e peso próprio real. Uma ferragem que apenas freia não equivale a um retentor positivo para retirar o saco; duas peças não autorizam dobrar uma carga publicada sem indicação do fabricante. A posição de montagem precisa respeitar os volumes do tanque e hidráulica e manter desmontagem acessível.

Foi preparada [ficha para consulta técnica](Ficha_consulta_tecnica.md), ainda **não enviada**. Ela registra os dados disponíveis e as respostas objetivas necessárias; não promete fabricação ou aprovação. Sem essas confirmações, a R40 mantém os movimentos ideais identificados como estudo.
