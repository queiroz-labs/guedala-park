# Escritório e hóspedes

[Início](../../README.md) · [Resumo](../Resumo.md) · [Registro de decisões](../Registro_de_decisoes.md)

A estação deve ficar de frente para a janela. A prioridade é conforto para trabalhar, depois receber hóspedes e depois armazenamento. O tipo de cama ou sofá-cama continua sem escolha.
