Base e limites do estudo

Pé-direito do escritório: 2,47 m como cenário. Na cozinha, 2,57 m até a laje é hipótese ainda a validar. Demais alturas de paredes são ilustrativas. Contorno baseado na planta oficial; portas e janelas reconstituídas graficamente. As animações demonstram mudanças de uso; não validam mecanismos, colisões, ferragens ou acessibilidade.

Vinílico definido na casa, exceto banheiro e lavanderia. Olmo é a preferência; Aveia e Bétula permanecem alternativas para comparar amostras. As cores não equivalem a códigos de fabricação. Preços não são cotações atuais. Equipamentos futuros e produtos candidatos aparecem identificados como estudo.

No computador e no celular

Este arquivo funciona sozinho, sem baixar bibliotecas. No celular, abra o HTML em um navegador que permita arquivos locais. Se o gerenciador abrir apenas uma prévia, use “Abrir com” o navegador. A versão web usa este endereço no GitHub Pages; a cópia HTML também funciona localmente.

Por dentro dos armários

É só explorar.

Este é o projeto do nosso apartamento. Os desenhos ajudam a imaginar os espaços; os móveis e as cores são representações aproximadas.

  1. Entre em um ambiente. Use os cartões no início da página.
  2. Mude o jeito de usar. Os botões abaixo do desenho abrem o sofá, a mesa e outros móveis.
  3. Toque em um móvel. Sua ficha mostra materiais, medidas e escolhas.

Arraste o desenho para girar. Use a roda do mouse, a pinça com dois dedos ou os botões + e − para aproximar. “Centralizar” recupera a vista.
