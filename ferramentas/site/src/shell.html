Base e limites do estudo

{{HEIGHT_STUDY}} Ver na planta. O contorno segue a planta oficial; portas e janelas são aproximadas. As animações mostram como cada espaço muda de uso, mas não testam mecanismos, ferragens ou acessibilidade.

Vinílico definido na casa, exceto banheiro e lavanderia. Olmo é a preferência. Aveia e Bétula ficam como alternativas para comparar amostras. As cores não equivalem a códigos de fabricação. Preços não são cotações atuais. Equipamentos futuros e produtos candidatos aparecem identificados como estudo.

No computador e no celular

Este arquivo funciona sozinho, sem baixar bibliotecas. No celular, abra o HTML em um navegador que permita arquivos locais. Se o gerenciador abrir apenas uma prévia, use “Abrir com” o navegador. A versão web usa este endereço no GitHub Pages. A cópia HTML também funciona localmente.

GUEDALA PARK · Projeto em desenvolvimento Projeto, medidas e amostras sujeitos à conferência.

Por dentro dos armários

É só explorar.

Este é o projeto do meu apartamento. Os desenhos ajudam a imaginar os espaços. Os móveis e as cores são representações aproximadas.

  1. Entre em um ambiente. Use os cartões no início da página.
  2. Consulte as medidas. Escolha um móvel na consulta rápida para ver sua ficha e isolá-lo no desenho.
  3. Toque em um móvel. Sua ficha mostra materiais, medidas e escolhas.

Arraste o desenho para girar. Use a roda do mouse, a pinça com dois dedos ou os botões + e − para aproximar. “Centralizar” recupera a vista.
